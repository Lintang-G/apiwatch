# apiwatch
A web application that allows registered users to monitor HTTP/HTTPS endpoints, track availability, analyze response times and receive notifications when monitored services become unavailable.

Primary objectives
- Build a complete full-stack application.
- Understand REST API design and database architecture.
- Implement asynchronous background processing.
- Understand HTTP networking and failure handling.
- Apply security principles, particularly SSRF prevention.
- Deploy a working application to the internet.
